코드 분석에서 찾은 것

실험 전에 공식 코드를 읽고 논문 개념이 어디에 구현되어 있는지 매핑했다. 이 중 1·3·4번이 이후 실험 방향을 정했다.

#발견근거이후 확인 결과
1단일 이미지 heatmap은 학습 안 된 seg branch에서 나온 값배포 checkpoint에 seg_decoder, neck_seg 가중치 없음 (key 직접 확인)heatmap은 실험 근거에서 제외. DetSeg-R internal 경로 제외
2VPHM(시간 smoothing)은 동작하는 구현이 없음VanishingPointGuidedCost가 미정의 변수를 쓰고 호출처 없음프로젝트 범위에서 제외
3UN query의 text attention mask가 decoder까지 전달되지 않는 것으로 보임query_text_mask를 만들지만 text cross-attention은 사용하지 않음ID branch가 차를 'objects'로 남긴 경우는 오탐의 8%뿐 → 재현 실패의 주원인은 아님
4IE-NMS 기준값이 하드코딩코드 [0.2]×11 + [0.5]×8, 논문은 Cityscapes로 class별 보정 (예: car 0.36)재현 실패의 직접 원인으로 확인 (R3)

DetSeg 파이프라인: 이미지 → 후보 box(ID 900 + UN 300 query) → IE-NMS(확실한 ID box를 ×2 강화해 겹치는 UN box 제거) → label 0이고 점수 0.2 초과만 OoD로 유지 → SAM으로 mask 생성.

평균 IoU로는 안 보이는 개선

FS L&F에서 작은 물체 검출률 30.2 → 54.3, 0점 이미지 52 → 33, IoU 중앙값 0 → 7.7로 크게 좋아졌는데 평균 IoU는 20.96 → 20.57로 그대로였다. 작은 물체를 새로 찾아도 이미지별 IoU 이득이 작고, 함께 늘어난 작은 오탐이 다른 이미지 점수를 깎는다.

Exp-E3 · 2026-10-13

탐색용물체 단위 지표 + road-aware 결합

물체 단위 지표 (SMIYC 방식 근사 구현)
  • sIoU: 정답 물체마다 맞닿은 예측 영역과의 IoU, 물체 평균. "놓치지 않았나"
  • PPV: 예측 영역마다 정답 위에 있는 비율. "헛것을 안 잡았나"
  • mean F1: 기준 0.25~0.75에서 맞춘 물체·놓친 물체·오탐 수로 F1을 구해 평균
  • 합성 데이터로 손계산 결과와 일치 확인
road-aware: 별도 모델 없이 detector 자신의 road box 사용
  • box 바닥 중앙점이 'road' box(label 1, 점수 > 0.2) 밖이면 점수 ×0.5 (soft)
  • 사전 분석: 정답 장애물의 99%(FS), 90%(RA)가 road box 위. 작은 오탐은 55% / 48%만
  • 사다리꼴 위치 prior는 정답을 28~42% 잃어 제외
  • hard 필터는 RA에서 도로 밖 큰 이상물체를 잃어 soft 채택

Summary

정리: 확인된 것 / 기각된 것 / 주의할 것

확인된 것
  • 공개 코드·checkpoint로는 FS L&F 논문 수치가 재현되지 않는다 (14.26 vs 32.36). RA는 오히려 높다.
  • 직접 원인은 IE-NMS 기준값(0.5)이 이 checkpoint의 ID 점수 분포(중앙 0.26)보다 높게 하드코딩된 것.
  • 작은 장애물 손실은 낮은 objectness 점수와 해상도 부족 때문이다.
  • 세 후처리 장치는 지표에서 역할이 분리된다 (ablation 성립).
  • detector 자신의 road box만으로 도로 문맥을 쓸 수 있다.
기각된 것
  • "IE-NMS가 작은 장애물을 지운다" (NMS 손실 6%)
  • "attention mask 미적용이 재현 실패의 주원인" (오탐의 8%)
  • 장애물형 class 보호 규칙 (효과 없음)
  • 사다리꼴 위치 prior (정답 손실 과다)
  • 채점 방식 차이 (전체 픽셀 IoU가 더 낮음)
주의할 것
  • 개선 수치는 모두 탐색용. 설정값을 평가 데이터를 보며 골랐다.
  • 이미지 평균 IoU는 작은 장애물 개선을 잘 반영하지 못한다. 물체 단위 지표를 함께 보고한다.
  • FS Static(이 버전)은 10/30장에 OoD가 없어 최대 66.7. 논문과 다른 버전으로 추정.
  • 작은 표본: FS 큰 물체 16개, RA 60장.
  • 비교 기준은 논문 수치가 아니라 우리가 직접 돌린 원본 결과다.
