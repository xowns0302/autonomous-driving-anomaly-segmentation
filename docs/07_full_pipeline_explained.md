# 07. 사진 한 장이 점수가 되기까지: 등장인물과 흐름

- 대상: DetSeg-S (DetSeg-R은 8절)
- 예시 숫자: FS L&F 이미지 (2048×1024), 공개 가중치
- 관련: [04 코드 위치](04_code_walkthrough.md), [06 판단 기준과 실제 숫자](06_decision_logic.md)

---

## 1. 전체 흐름 한 장

```
                        ┌──────────── 글자 쪽 ────────────┐
 "objects. road. ... bicycle."  →  ② BERT  →  글자 벡터 (단어마다 256개 숫자)
                                                     │
 사진 2048×1024  →  ① 축소·정규화  →  ③ Swin-B  →  ④ Neck  →  이미지 벡터 (약 1.9만 칸 × 256개 숫자)
                                                     │
                                         ⑤ Encoder: 이미지와 글자를 서로 보며 섞기
                                                     │
                              ⑥ 후보 위치 고르기:  ID용 900칸 / UN용 300칸
                                                     │
                                         ⑦ Decoder 6층: 후보마다 상자 다듬기
                                                     │
                     ⑧ Head 3개: class 점수 / 상자 좌표 / 물체 점수
                                                     │
                     ⑨ IE-NMS (규칙): 아는 물체가 겹치는 이상 후보 지우기
                                                     │
                     ⑩ 최종 걸러내기 (규칙): 아는 물체 버리고, 물체 점수 > 0.2
                                                     │
                     ⑪ SAM: 상자마다 물체 모양 그리기 → 합치기
                                                     │
                     ⑫ 채점 (규칙): 정답 그림과 픽셀 비교 → IoU
```

①②③④⑤⑥⑦⑧은 **학습된 신경망**, ⑨⑩⑫는 **사람이 정한 규칙**, ⑪은 **다른 회사의 학습된 신경망**이다.

## 2. 등장인물 소개

| # | 이름 | 정체 | 만든 곳 | 무엇으로 배웠나 | 능력 | DetSeg에서 |
|---|---|---|---|---|---|---|
| ② | **BERT** (bert-base-uncased) | 언어 모델 | Google (2018) | 영어 위키백과 + 책 (BooksCorpus) | 단어를 "뜻이 담긴 숫자 묶음(벡터)"으로 바꾼다. 비슷한 뜻 → 비슷한 숫자 | 고정 (학습 안 함) |
| ③ | **Swin Transformer-B** | 이미지 모델 (backbone) | Microsoft (2021) | ImageNet-22K (약 1,400만 장, 2만여 종류) → 이후 Grounding DINO 학습 때 함께 조정 | 사진을 "무엇이 어디 있는지" 담긴 숫자 지도로 바꾼다. 4가지 크기(세밀~대략)로 | 고정 |
| ④ | **Neck** (ChannelMapper) | 연결부 | OpenMMLab | Grounding DINO 학습 | Swin의 출력을 크기 맞춰(256) 다음 단계로 넘긴다 | 고정 |
| ⑤⑥⑦⑧ | **Grounding DINO** (Encoder·Decoder·Head) | "글자로 지정한 물체를 찾는" 검출기 | 원 구조: IDEA Research (2023). 우리가 쓰는 가중치: **MM-Grounding-DINO** (OpenMMLab) | Objects365, GoldG, V3Det, COCO, LVIS, GRIT, RefCOCO 계열 등 대규모 "이미지-글자-상자" 데이터 | "car"라고 말하면 차를 찾는다. 처음 보는 단어도 어느 정도 찾는다 (open-vocabulary) | 고정 |
| ⑥⑧ | **UN query + 물체 점수 head** (+ universal token) | DetSeg가 **새로 붙인** 부분 | DetSeg 저자 (2025) | **COCO** (80종 물체 상자). 모든 물체를 그냥 "물체"로 학습, 1 epoch | 종류와 상관없이 "여기 물체가 있다"를 찾는다 | **이 부분만 학습됨** |
| ⑨⑩ | **IE-NMS, 최종 필터** | 규칙 (계산식) | DetSeg 저자 | 학습 없음. 숫자(bar, ×2, IoU 0.5, τ 0.2)는 사람이 정함 | 아는 물체를 빼고 이상 물체만 남긴다 | 코드 |
| ⑪ | **SAM** (ViT-B) | "상자/점을 주면 물체 모양을 따라 그려주는" 모델 | Meta (2023) | **SA-1B**: 1,100만 장 사진, 11억 개 mask | 상자 안의 물체 윤곽을 정확히 그린다. **그 물체가 뭔지·이상한지는 모른다** | 고정 |
| ⑫ | **채점** | 규칙 | DetSeg 저자 (지표 정의는 연구계 표준) | – | 예측 그림과 정답 그림을 픽셀로 비교 | 코드 |
| 정답 | **정답 그림** | 사람이 칠한 mask | 각 데이터셋 제작팀 | – | 이상 = 1, 정상 = 0, 제외 = 255 | 데이터 |

**핵심:** DetSeg 저자가 직접 학습시킨 건 ⑥⑧의 **UN query 관련 작은 부분**뿐이다. 나머지는 Google·Microsoft·OpenMMLab·Meta가 학습해 공개한 모델을 그대로 조립했다.

## 3. 단계별 상세

### ① 입력 준비 (규칙)
- 사진 2048×1024 → **1333×666**으로 축소 (가로세로 비율 유지, Grounding DINO 표준 크기)
- 픽셀값(0~255)을 평균·표준편차로 정규화 (학습 때와 같은 조건으로 맞추기)
- **영향:** 작은 물체가 약 0.65배로 더 작아진다 (16px 미만 장애물을 놓치는 원인 중 하나)

### ② 글자 → 벡터 (BERT)
- 입력 글자: `"objects. road. sidewalk. building. … motorcycle. bicycle."`
  - 19개는 Cityscapes class 이름 = **"아는 물체" 목록**
  - 맨 앞 'objects'는 DetSeg가 붙인 **"아무 물체" 자리**. 여기에 DetSeg가 학습한 universal token 벡터를 더한다
- BERT가 단어(토큰)마다 숫자 묶음을 만든다 → 이후 256개 숫자로 맞춤

### ③④ 사진 → 숫자 지도 (Swin-B + Neck)
- 사진을 작은 조각으로 나눠 보고, 주변 조각들과 비교하며 "여기에 바퀴 같은 무늬, 저기에 하늘 같은 색"을 숫자로 요약
- 4가지 해상도의 지도: 167×84, 84×42, 42×21, 21×11 칸 → **합계 약 18,700칸**, 칸마다 256개 숫자
- 세밀한 지도(167×84)는 작은 물체, 대략적인 지도(21×11)는 큰 물체를 보기 좋다

### ⑤ Encoder: 이미지와 글자 섞기 (Grounding DINO, 6층)
- 이미지 칸들이 **글자를 참고**하고, 글자들이 **이미지를 참고**한다 (cross-attention)
- 결과: "이 칸은 'car'라는 단어와 관련이 높다" 같은 정보가 각 칸에 섞여 들어간다

### ⑥ 후보 위치 고르기 (Query Selection)
- **ID용:** 18,700칸 각각이 19개+1개 단어와 얼마나 맞는지 점수 → 가장 높은 **900칸**을 출발점으로
- **UN용 (DetSeg 추가):** 각 칸에 "물체 같은가" 점수 → 가장 높은 **300칸**
- 고른 칸마다 대략적인 상자(위치·크기)를 하나씩 가진다

### ⑦ Decoder: 상자 다듬기 (6층)
- 1,200개 후보(query)가 층마다 ① 서로를 보고(중복 조정), ② 글자를 보고, ③ 이미지 주변을 다시 보며 상자를 조금씩 고친다
- **칸막이:** ID팀 900과 UN팀 300은 서로를 못 보게 막혀 있다 (각자 일만 하게)
  - 논문은 "UN팀은 class 이름 글자도 못 보게" 막는다고 했지만, 공개 코드에서는 이 글자 칸막이가 실제로 적용되지 않는다

### ⑧ Head: 점수와 좌표 계산
| head | 계산 | 출력 |
|---|---|---|
| class (ID팀) | 후보 벡터와 각 단어 벡터의 **내적**(얼마나 같은 방향인가) → sigmoid로 0~1 | 20개 단어별 점수. 가장 높은 단어 = 그 상자의 label |
| 좌표 (공통) | 작은 신경망(MLP)이 상자를 보정 | (x1, y1, x2, y2) |
| 물체 점수 (UN팀, DetSeg 추가) | 작은 신경망(MLP) → sigmoid | 0~1 "물체다" |

- ID팀 900개 × 20단어 점수 중 높은 **300개 (상자, 단어)** 쌍, UN팀은 물체 점수 높은 **300개** → **후보 600개**
- 이 단계까지가 "학습된 신경망"이 하는 일. 여기서부터는 **규칙**이다

### ⑨ IE-NMS (규칙)
1. ID 상자 중 class 점수가 그 class의 **bar**를 넘으면 "확실한 아는 물체" → 점수 ×2 (bar: 공개 코드 stuff 0.2 / thing 0.5)
2. 점수 높은 상자부터 차례로 보며, 이미 남긴 상자와 **IoU > 0.5**로 겹치면 지운다 (class 무관)
3. 점수 원래대로

→ "확실한 차"가 같은 자리의 "물체 후보"를 지운다

### ⑩ 최종 걸러내기 (규칙)
- 아는 물체 상자(label 1~19)는 모두 버림
- 남은 상자 중 **점수 > τ (0.2)** 만 남김 → **이상 물체 상자**

### ⑪ SAM: 모양 그리기
- SAM이 사진 전체를 한 번 보고(이미지 encoder) → 상자마다 "이 상자 안 물체" 모양을 그림
- 상자 하나에 후보 모양 3개가 나오는데 코드는 **첫 번째**를 쓴다
- 모든 모양을 합쳐(OR) 한 장의 예측 그림 (이상 = 1)
- **SAM은 상자를 의심하지 않는다.** 상자가 틀리면(차 위) 차 모양을 그대로 그린다

### ⑫ 채점 (규칙)
- 정답 그림(사람이 칠함)과 예측 그림을 같은 크기로 겹침
- **IoU = 둘 다 이상인 픽셀 ÷ 하나라도 이상인 픽셀** (정답 255 픽셀 제외)
- 모든 이미지 IoU의 **평균** = 데이터셋 점수

## 4. 판단의 근거는 결국 무엇인가

| 질문 | 답 |
|---|---|
| "이게 차다"는 근거 | Grounding DINO가 대규모 이미지-글자 데이터로 배운 **"car" 단어와 이미지 특징의 유사도** |
| "여기 물체가 있다"는 근거 | DetSeg가 COCO로 학습시킨 **물체 점수** ("COCO 80종 같은 것들이 물체다"를 일반화) |
| "이건 이상 물체다"는 근거 | **규칙:** 물체 점수는 높은데(> 0.2), 그 자리에 "확실한 아는 물체"(bar 초과)가 없다 |
| 모양의 근거 | SAM이 11억 개 mask로 배운 "물체 경계" 감각 |
| 맞았는지의 근거 | 데이터셋 제작자가 칠한 정답 그림 |

따라서 실패도 두 종류다.
- **신경망의 한계:** 물체 점수가 낮게 나옴(작은 장애물), class 점수가 낮게 나옴(차인데 0.26)
- **규칙의 한계:** bar가 점수 분포와 안 맞음(공개 코드), 이상 물체가 아는 물체처럼 보이면 지워짐(IE-NMS 구조)

우리 개선(Phase 3)은 신경망은 그대로 두고 **규칙(⑨⑩)과 입력(①)**을 바꾼다.

## 5. DetSeg-R: 등장인물 하나 추가

| 이름 | 정체 | 만든 곳 | 무엇으로 배웠나 | 능력 |
|---|---|---|---|---|
| **Mask2Anomaly** | 픽셀 분류 모델 (ResNet-50 + Mask2Former 구조) | Rai et al., ICCV 2023 | Cityscapes(19 class로 픽셀 분류) → COCO 물체를 붙여 넣은 사진으로 추가 학습 | 픽셀마다 "19개 중 무엇인가"를 맞힌다. **어느 것에도 자신 없으면 이상**으로 본다 |

흐름:
1. Mask2Anomaly: 픽셀마다 19개 class 확률 → **이상 점수 = 1 − (가장 높은 확률)** (좌우 반전 사진 결과와 평균)
2. DetSeg ①~⑩ 그대로 → 이상 물체 상자
3. 상자 **안쪽** 픽셀의 이상 점수 **+1.0** → 상자 밖의 흩어진 오탐이 상대적으로 낮아짐
4. 채점: 픽셀 점수 지도용 지표 (AUROC·AP·FPR95, 최적 threshold IoU)
