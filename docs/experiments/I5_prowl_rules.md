- 신호: proto_box = 1 − max cos(box 안 DINOv2 특징 평균, Cityscapes train prototype 380개) ([P1](P1_prowl_presignal.md))
- 결론:

  - **C7 (제거) 선택, 검증 효과 미미:** 튜닝셋 +2.35, 검증셋 +0.11 / +0.07. 성공 기준은 형식상 충족하지만 실질적 개선은 FS L&F에 한정

## 4. 해석

1. **C6가 실패한 이유: RA의 "아는 물체"가 Cityscapes prototype과 닮지 않았다.** P1에서 RA의 지운 후보 구분 AUC는 0.79로 M2A(0.72)보다 높았지만, 오탐 수(460)가 진짜(277)보다 많고 오탐의 신호 분포가 넓다(90백분위 0.54). 보호 기준을 넘는 오탐(인터넷 사진 속 사람·차·풍경)이 많이 살아나 IoU가 크게 떨어진다. M2A는 픽셀 분류기라 같은 사진에서도 사람·차를 더 잘 알아본다
2. **C7은 FS L&F의 남은 오탐을 정확히 지운다** (DetSeg-S 24.26 → 29.72, DetSeg-R AP 73.19 → 78.60). P1의 사전 분석(남은 후보 AUC 0.941)과 일치한다
3. **C7이 검증셋에서 효과가 없는 이유:** SMIYC Obstacle은 남은 오탐이 원래 적고(시골길, 이미지당 box 약 2.7개), SMIYC Anomaly의 주된 문제는 오탐이 아니라 **과잉 억제**(진짜 이상 물체가 지워짐)다. C7은 지우기만 하므로 과잉 억제를 고치지 못한다
4. **두 신호는 서로 다른 문제에 강하다:**
   - M2A (C5): 과잉 억제 방지 (SMIYC Anomaly +23.5)
   - PROWL (C7): Cityscapes에 있는 물체 위 오탐 제거 (FS L&F DetSeg-R AP +5.4)
   → 둘을 함께 쓰는 조합(C5 + C7)이 자연스러운 다음 후보다
