# A3. IE-NMS bar를 논문 방식으로 보정

- 날짜: 2026-10-17
- 단계: Phase 2 (분석). 논문에는 있지만 공개 코드에 없는 절차를 복원한다

## 1. 목적

논문 3.1절의 IE-NMS bar 보정 절차를 공개 가중치에 적용하면 (1) bar가 얼마가 나오는가, (2) 재현 성능이 논문에 가까워지는가?

## 2. 방법

**논문 문장:** "Cityscapes 일부에서 class마다 예측 box와 정답 box를 1:1 매칭하고, IoU < 0.5 쌍(AP50 기준)을 버린 뒤, 최소 classification score를 그 class의 bar로 기록한다."

**우리 구현** (`src/calibrate_ie_nms_bars.py`):

| 항목 | 내용 | 논문에 명시? |
|---|---|---|
| 데이터 | Cityscapes **val 500장 전체** (gtFine + leftImg8bit) | "subset"이라고만 |
| 예측 | 공개 가중치의 ID branch box (label 1~19, 이미지당 상위 300개). IE-NMS에 들어가는 그 입력 | 명시 안 됨 |
| 정답 box | thing 8개 class: gtFine `instanceIds`의 개별 물체. 개별 id가 없는 군집(crowd) 영역은 제외 | 명시 안 됨 |
| 매칭 | 이미지·class마다 예측을 점수 높은 순으로, IoU ≥ 0.5인 남은 정답 중 IoU 최대인 것과 1:1 매칭 (AP50 계산 방식) | "1:1, IoU < 0.5 제거" |
| bar | 매칭된 예측 점수의 **최소값** | ✅ |
| stuff 11개 class | Cityscapes에 개별 물체 라벨이 없음 → (V1) 공개값 0.2 유지 / (V2) class 영역의 연결 덩어리(100px 이상)를 정답 box로 보고 보정 (우리 해석) | 명시 안 됨 |

**평가 변형 (실행 전에 고정):**

| 변형 | thing bar | stuff bar | 성격 |
|---|---|---|---|
| 공개본 | 0.5 | 0.2 | E1·E3 결과 |
| **V1** | Cityscapes 최소값 | 0.2 (공개값) | **논문 방식** |
| V2 | Cityscapes 최소값 | Cityscapes 최소값 (연결 덩어리) | 우리 해석, 참고 |
| V3 | Cityscapes 10% 분위수 | 0.2 | 최소값 민감도 확인 |

bar 적용: `src/run_with_bars.py`가 공식 `tools/test.py`를 그대로 실행하되 `_ie_nms`만 같은 로직 + 보정 bar로 교체. **공개 bar를 넣으면 공식 결과(FS L&F 14.26)와 똑같이 나옴을 확인.** DetSeg-S, DetSeg-R(M2A) 모두 공식 config·지표 그대로.

## 5. 해석

1. **논문 방식 보정은 FS L&F의 재현 격차를 크게 줄인다.** DetSeg-S FS L&F 14.26 → 24.26. 논문과의 차이가 18.1 → 8.1로 줄어 판정이 **"불일치" → "부분 재현"**으로 바뀐다. FS Static도 +12.1. 공개본 재현 실패의 상당 부분이 "보정 절차 누락 + 옛 bar 잔존"으로 설명된다
2. **그러나 SMIYC Anomaly는 크게 나빠진다** (DetSeg-S 69.12 → 54.57, DetSeg-R IoU 71.15 → 58.29). bar를 낮추면 이상 물체를 ID 물체로 잘못 본 box도 더 쉽게 강화되어 진짜 이상 물체를 지운다. A2에서 본 과잉 억제가 늘어난 것이다 (A2 이미지 5의 truck 사례와 같은 방향)
3. **같은 bar로 두 방향의 실패를 동시에 고칠 수 없다.** bar를 낮추면 과소 억제(FS L&F의 차량 오탐)는 줄고 과잉 억제(SMIYC Anomaly)는 늘어난다. bar 하나의 높낮이가 아니라 **"언제 ID box가 OoD box를 지워도 되는가"라는 규칙 자체**를 바꿔야 한다
4. **DetSeg-R은 bar 보정 효과가 작거나 섞여 있다.** FS L&F에서 AP·FPR95는 좋아지지만(70.84 → 73.19, 9.39 → 8.09) 최적 IoU는 떨어진다. DetSeg-R은 box 밖 점수만 상대적으로 낮추므로, box 수가 줄 때 이득과 손해가 함께 생긴다
5. **SMIYC Obstacle은 변하지 않는다.** 장면에 ID 물체가 거의 없어 IE-NMS가 할 일이 없다 (E4와 일치)
6. V2(stuff까지 보정)는 V1과 비슷하다(RA·SMIYC Anomaly 약간 좋음, FS L&F 약간 나쁨). V3(p10, 더 높은 bar)는 FS L&F 효과가 줄어 중간값이다 → 결과가 bar 값에 단조롭게 반응한다

## 6. 다음 단계로 넘기는 것

- 재현 결론: **"공개본 + 논문 방식 bar 보정"**을 우리 환경의 DetSeg 기준선으로 삼을 수 있다 (FS L&F 24.26, RA 79.25, SMIYC Obstacle 77.93). 단 SMIYC Anomaly에서는 공개본보다 나쁘다
- 개선 방향 후보: bar 높낮이가 아니라 **과잉 억제를 막는 억제 규칙** (예: OoD 점수가 높은 box는 ID box가 지우지 못하게, stuff class는 억제에서 제외 등)
- **주의 (데이터 누수):** SMIYC Anomaly는 검증셋으로 정해 두었는데, 재현·분석 단계에서 이미 결과와 실패 이미지(A2)를 보았다. 개선 설계가 이 관찰에 영향을 받았다는 점을 보고서에 명시하고, **하이퍼파라미터는 튜닝셋(FS L&F + RA)에서만** 정한다
