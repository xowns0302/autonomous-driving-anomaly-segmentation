# I6. C5 + C7 조합 (C8): M2A 보호 + PROWL 제거

- 날짜: 2026-10-18
- 단계: Phase 3 (개선), 계획: [05_improvement_plan.md](../05_improvement_plan.md) 8절 (실행 전 등록)
- 결론: **튜닝셋에서 C5보다 좋아 채택했고, 검증셋 두 곳 모두 기준선보다 좋다 (성공 기준 충족).** 그러나 SMIYC Anomaly에서는 **C5 단독보다 8.5 낮다.** 일반화는 C5가 더 좋고, C8은 "도시 도로 + 작은 장애물(FS L&F)"에 특화된 선택지다. 처리 시간이 가장 길다

## 1. 규칙

1. IE-NMS: OoD box 안 M2A 점수 평균 ≥ 0.5이면 ID box가 지우지 못한다 (C5, I4에서 고른 값 고정)
2. IE-NMS 뒤: proto_box < t7인 OoD box는 버린다 (C7)
- 구현: `src/run_with_bars.py --m2a-dir ... --verify-t 0.5 --prowl-bank results/P1/prototypes.npz --reject-t7 t7`
- 실행: `scripts/tune_c8.sh`, `scripts/eval_c8.sh`

## 5. 해석

1. **C8은 FS L&F(도시 도로, 작은 장애물)에서 가장 좋다.** DetSeg-S 38.44 (논문 32.36보다 높음), DetSeg-R AP 83.15 (M2A 단독 69.44 대비 +13.7). M2A가 진짜 이상 물체를 지키고, PROWL이 울타리·기둥·차 위 오탐을 지운다
2. **SMIYC Anomaly에서는 C7의 제거가 진짜 이상 물체도 일부 지운다** (C5 78.06 → C8 69.58). SMIYC Anomaly의 이상 물체는 크고 다양하며(동물, 특이한 차량 등), 일부는 Cityscapes prototype(사람, 트럭 등)과 닮아 "아는 물체"로 판정된다. 튜닝셋인 FS L&F의 작은 장애물(상자, 타이어 등)은 prototype과 덜 닮아 이 문제가 드러나지 않았다
3. 즉 **C7의 t7은 데이터셋의 "이상 물체가 아는 물체와 얼마나 닮았나"에 민감하다.** 튜닝셋이 검증셋의 이상 물체 분포를 대표하지 못했다 (튜닝셋에서 C8 > C5였지만 검증셋에서 역전)
4. **최종 정리:**
   - **일반화가 가장 좋은 방법: C5** (검증셋 두 곳 모두 큰 개선, DetSeg-R도 일관된 개선)
   - **도시 도로 작은 장애물에 가장 강한 방법: C8** (FS L&F 최고, SMIYC Obstacle은 C5와 같음). 대신 처리 시간이 가장 길고, 큰 이상 물체가 아는 물체를 닮은 경우 놓칠 수 있다
   - 보고서 서술: "C5와 C7을 조합하면 도시 도로 장애물 성능은 더 좋아지지만, 처리 시간이 늘고 아는 물체를 닮은 이상 물체를 놓치는 trade-off가 있다"
