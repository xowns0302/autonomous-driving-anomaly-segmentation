# I1. 억제 규칙 개선 (C1 배경 제외, C2 높은 objectness 보호) — 기각

- 날짜: 2026-10-17
- 단계: Phase 3 (개선), 계획: [05_improvement_plan.md](../05_improvement_plan.md)
- 결론: **두 규칙 모두 튜닝셋에서 기준선보다 크게 나빠져 기각.** 검증셋(SMIYC)은 사용하지 않았다

## 1. 목적

A2·A3에서 본 과잉 억제(진짜 이상 물체가 ID box에 지워짐)를 막는다.
- **C1:** 배경 class(road, sidewalk, building, wall, vegetation, terrain, sky)의 ID box는 OoD box를 지우지 못한다
- **C2:** objectness ≥ γ인 OoD box는 ID box가 지우지 못한다

## 2. 설정

- 기준선: 공개 코드 + 논문 방식 bar (A3 V1, `results/A3/bars_things.json`의 최소값)
- 구현: `src/sweep_ie_nms_bars.py`의 `ie_nms_rules` (규칙을 끄면 원래 IE-NMS와 230장 모두 결과가 같음을 확인), `src/run_with_bars.py --background-exempt --protect-gamma γ`
- 튜닝셋: FS L&F + Road Anomaly, DetSeg-S IoU. γ ∈ {0.5, 0.6, 0.7, 0.8} (계획에서 미리 정한 값)

## 4. 왜 나빠졌나 (`src/analyze_rule_effect.py`, 저장된 후보로 오프라인 분석)

| 데이터 | 설정 | 최종 box | 오탐 | 규칙 때문에 **새로 살아난 box** | 그중 오탐 | 새 box 크기 (중앙 / 상위 10%) | 새 box objectness 중앙 |
|---|---|---|---|---|---|---|---|
| FS L&F | 기준선 | 323 | 234 | – | – | – | – |
| FS L&F | C1 | 418 | 329 | 95 | **95 (100%)** | 12,913 / **1,183,634 px** | 0.24 |
| FS L&F | C2 γ=0.8 | 611 | 522 | 288 | **288 (100%)** | 29,483 / 123,062 px | **0.88** |
| Road Anomaly | C1 | 484 | 263 | 57 | 39 | 369,245 / 710,129 px | 0.26 |
| Road Anomaly | C2 γ=0.8 | 467 | 261 | 40 | 37 | 4,778 / 34,841 px | **0.85** |

1. **C1이 실패한 이유: 배경 box가 "좋은 일"도 하고 있었다.** UN query는 도로·건물·숲 같은 넓은 배경 영역에도 box를 만든다. 지금까지는 같은 영역의 배경 ID box(road, building 등)가 이런 box를 지워 왔다. C1로 그 억제를 막자 **이미지 대부분을 덮는 거대한 오탐 box**(상위 10%가 약 118만 px, 2048×1024 이미지의 56%)가 살아났다. A2의 이미지 4(큰 이상 물체가 road box에 지워짐)는 이 큰 이득 옆의 드문 부작용이었다
2. **C2가 실패한 이유: objectness는 "이상함"이 아니라 "COCO 물체다움"이다.** UN query는 COCO로 학습했고, COCO에는 차·사람·자전거가 들어 있다. 그래서 **차·사람 같은 아는 물체에 objectness를 오히려 가장 높게** 준다 (새로 살아난 오탐의 중앙 0.88). γ를 0.8까지 올려도 이런 box가 수백 개 살아난다. A2 이미지 5의 이상 물체(0.749)보다 아는 물체가 더 "물체답다"
3. 따라서 **IE-NMS의 과잉 억제는 점수 기반 규칙으로 막기 어렵다.** 이상 물체가 ID 물체처럼 보일 때 지워지는 것은 "아는 물체를 지운다"는 DetSeg 패러다임 자체의 한계이며, 이를 구분할 정보(objectness, 배경 여부)가 현재 모델 출력에 없다

## 5. 결정

- 튜닝셋 최고 설정 = **기준선 (규칙 없음)** → C1·C2 기각. 계획(05 문서 4절)대로 검증셋에서는 평가하지 않는다
- 이 결과는 **부정적 결과로 보고서에 포함**한다. 근거: 규칙 효과의 정량 분석(새로 살아난 box의 100%가 오탐), objectness의 성질
- 다음: 계획 순서대로 **C3 (도로 문맥 재점수화)**, **C4 (고해상도 추론)**. 둘 다 과잉 억제가 아니라 튜닝셋의 남은 주요 문제(도로 밖 오탐, 작은 물체 누락)를 겨냥한다
