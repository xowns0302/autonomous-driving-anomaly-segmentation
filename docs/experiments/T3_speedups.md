## 4. 해석

1. **가장 큰 이득은 SAM이다** (437 → 227 ms). 낭비였던 CPU 전·후처리가 줄었다. 남은 SAM 시간은 이미지 encoder(약 120 ms, GPU)와 이미지 1회 전처리다
2. **box가 많을수록 이득이 크다.** SAM 후처리가 box 수에 비례했기 때문이다 (FS L&F 공개본 −34% vs box가 적은 SMIYC Obstacle −17%)
3. **DetSeg-R은 이득이 작다** (−3~11%). SAM을 쓰지 않아 BERT 재사용과 C7 개선만 해당되고, 남은 시간 대부분이 M2A(400~500 ms)다
4. **C5·C8의 남은 비용은 M2A다.** DetSeg-S + C5에서 M2A가 약 40~50%를 차지한다. 더 줄이려면 M2A 자체를 줄여야 한다 (좌우반전 생략 등, 결과가 바뀜 → 이번 범위 밖)
5. 남은 후보 (결과가 바뀔 수 있음): fp16, M2A 좌우반전 생략, 데이터 읽기를 계산과 겹치기(실제 배포에서는 이미지가 메모리로 들어오므로 측정 방식의 문제)
