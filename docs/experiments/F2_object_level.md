# F2. 물체 단위 신뢰성 지표: 놓친 이상 물체 수와 잘못 경보 수

- 날짜: 2026-10-19
- 목적: 점수(IoU)는 면적 비율이라 "위험한 물체를 몇 개 놓쳤나"가 직접 보이지 않는다. 자율주행 신뢰성과 바로 연결되는 물체 단위 지표를 센다
- 새 실행 없음: F1에서 저장한 DetSeg-S mask(공개 코드 / 베이스라인 / C5 / C8)를 그대로 사용
- 결론: **C5는 베이스라인보다 놓친 물체를 30개(16%) 줄였고(184 → 154), 공개 코드와 같은 수준으로 덜 놓치면서 잘못 경보는 61% 적다(729 → 284).** 대신 베이스라인보다 잘못 경보가 46개 많다

## 1. 정의 (실행 전에 고정)

| 용어 | 정의 |
|---|---|
| 정답 물체 | 정답 이상 영역의 8방향 연결 덩어리, 50px 이상 |
| 찾음 | 그 물체 면적의 50% 이상을 예측 mask가 칠함 |
| 놓침 | 찾지 못한 정답 물체 |
| 잘못 경보 | 예측 mask의 연결 덩어리(평가 제외 영역 밖, 50px 이상) 중 정답 이상 픽셀과 전혀 닿지 않는 것 |

스크립트: `src/count_missed_objects.py` → `results/F2/object_counts.csv`(이미지별), `results/F2/summary.md`

## 4. 해석

1. **기준선 보정(베이스라인)은 잘못 경보를 크게 줄였지만(729 → 238) 놓침을 늘렸다(154 → 184).** "덜 지움 ↔ 너무 지움"의 trade-off가 물체 단위로도 그대로 보인다
2. **C5는 놓침을 공개 코드 수준(154)으로 되돌리면서 잘못 경보는 그보다 61% 적다.** 두 실패를 함께 줄인 유일한 설정
3. **대가:** 베이스라인보다 잘못 경보가 +46 (대부분 RA +28, FS L&F +14). RA의 IoU 하락(A3·I4)과 같은 원인 (M2A가 인터넷 사진 속 정상 물체에도 높은 점수)
4. **C8**은 잘못 경보가 가장 적지만(148) 놓침이 C5보다 11개 많다 (C7이 아는 물체를 닮은 이상 물체를 지움)
5. 한계: 정답 물체를 연결 덩어리로 정의해서, 붙어 있는 여러 물체는 하나로 센다. 50px 미만의 아주 작은 조각은 제외했다
