## 4. 관찰

1. **검출(DetSeg 본체)은 약 190~210 ms로 데이터셋과 무관하게 일정하다.** 입력이 항상 1333 크기로 축소되기 때문이다
2. **SAM이 DetSeg-S 시간의 절반 가까이를 차지한다** (300~440 ms). 그중 GPU 계산(이미지 encoder 120 ms + mask decoder 10~18 ms)보다 **CPU 전·후처리(200~300 ms)가 더 크다**
3. **SAM 후처리 시간은 box 수에 비례한다.** box마다 mask 3장을 CPU에서 원본 크기로 키우기 때문이다. box가 적은 SMIYC Obstacle(약 2.7개)은 39 ms, FS L&F 공개본(약 10.5개)은 175 ms. 논문 방식 bar가 box를 줄여 DetSeg-S가 빨라진 것(808 → 603 ms)도 같은 이유다
4. **C5 비용은 대부분 M2A다** (394~498 ms). C5 규칙 자체는 10~40 ms다 (box 평균 계산 + 파이썬으로 짠 NMS)
5. **DetSeg-R은 M2A를 원래 쓰므로 C5 추가 비용이 20~50 ms에 그친다**
6. M2A의 2회 추론(원본 + 좌우반전)이 M2A 시간의 대부분이다

## 5. 최적화 후보 (다음 단계, T3)

| # | 대상 | 방법 | 결과 변화 | 근거 (위 측정) |
|---|---|---|---|---|
| O1 | SAM 후처리 | 사용하는 mask 1장만, GPU에서 원본 크기로 | 없어야 함 | 39~175 ms, box 수에 비례 |
| O2 | SAM 전처리 | 이미지 전처리 1회 + box 좌표 변환만 따로 | 없어야 함 | 68~138 ms |
| O3 | BERT | 같은 문장의 결과를 한 번 계산해 재사용 | 없어야 함 | 28 ms |
| O4 | C5 NMS | 파이썬 반복문 → 행렬 연산 | 없어야 함 | C5 10~40 ms |
| O5 | 검출·SAM | fp16 | 바뀔 수 있음 → IoU 재확인 | 검출 ~200 ms, SAM encoder 120 ms |
| O6 | M2A | 좌우반전 생략 | 점수 바뀜 → 재평가 | M2A의 약 절반 |

O1~O4는 **결과가 소수점까지 같아야** 하는 변경이다. 같은지 확인한 뒤 같은 스크립트로 T3를 측정한다.
