# I4. Mask2Anomaly로 확인하는 IE-NMS (C5) — 성공

- 날짜: 2026-10-17
- 단계: Phase 3 (개선), 계획: [05_improvement_plan.md](../05_improvement_plan.md) 6절 (실행 전 등록)
- 결론: **튜닝셋에서 고른 설정(t = 0.5)이 검증셋 두 곳 모두에서 기준선보다 좋다 → 성공 기준 충족.** DetSeg-S·R 모두 개선

## 1. 아이디어

IE-NMS는 "이 자리에 확실한 아는 물체가 있다"는 판단을 **Grounding DINO 하나**에만 맡긴다. 이상 물체가 아는 물체처럼 보이면(예: 트럭처럼 생긴 물체) 진짜 이상 물체가 지워진다 (A2·A3).

Mask2Anomaly(M2A)는 Cityscapes 픽셀 분류기로, **다른 데이터·다른 방식으로 배워 다른 곳에서 틀린다.** M2A는 차·사람 픽셀은 잘 알아 이상 점수를 낮게 주고, 처음 보는 물체에는 높게 준다.

**규칙 (C5):** ID box가 OoD box를 지우려 할 때, OoD box 안의 M2A 이상 점수 평균이 **t 이상이면 지우지 않는다.** 나머지(OoD끼리의 NMS, τ = 0.2, ID box 버리기)는 그대로.

사전 근거 (튜닝셋만, `src/analyze_m2a_box_signal.py`): IE-NMS가 지운 OoD 후보 중 진짜 이상 물체(M2A 중앙 0.70)와 오탐(0.04)을 AUC 0.946(FS L&F), 0.716(RA)으로 구분

## 2. 설정

- 기준선: 논문 방식 bar (A3 V1)
- 구현: `src/sweep_ie_nms_bars.py`의 `ie_nms_rules(verify_scores, verify_t)`, `src/run_with_bars.py --m2a-dir ... --verify-t t`. box 안 평균은 적분 영상으로 계산
- M2A 점수 지도: E2에서 만든 것 그대로 (`results/score_maps/m2a/`)
- 구현 확인: t = 1.1(규칙이 절대 발동하지 않는 값)에서 기준선과 같은 값 (24.26 / 79.25)

## 3. 튜닝 (FS L&F + Road Anomaly, DetSeg-S IoU)

| t | FS L&F | Road Anomaly | 평균 |
|---|---|---|---|
| 기준선 | 24.26 | 79.25 | 51.76 |
| 0.3 | 33.73 | 70.01 | 51.87 |
| **0.5** | **32.67** | 76.82 | **54.75 (+2.99)** |
| 0.7 | 26.19 | 78.18 | 52.19 |

→ t = 0.5 선택. t를 낮출수록 보호가 늘어 FS L&F는 오르고 RA는 내려간다 (RA는 M2A가 환경 차이로 정상 물체에도 높은 점수를 주는 경우가 있어 오탐도 함께 보호됨)

## 4. 검증 (t = 0.5 고정, 1회)

### 4.1 DetSeg-S IoU

| | SMIYC Obstacle | SMIYC Anomaly |
|---|---|---|
| 공개본 | 77.93 | 69.12 |
| 기준선 (논문 방식 bar) | 77.93 | 54.57 |
| **C5 (t 0.5)** | **80.93 (+3.00)** | **78.06 (+23.49)** |
| (논문 Table 2) | 81.58 | 75.82 |

**판정: 검증셋 두 곳 모두 개선 → 성공.** SMIYC Anomaly는 공개본(69.12)과 논문(75.82)보다도 높다.

### 4.2 DetSeg-R (Mask2Anomaly + DetSeg-R): AP / FPR95 / 최적 IoU

| Dataset | M2A 단독 (E2) | 기준선 (A3 V1) | **C5 (t 0.5)** |
|---|---|---|---|
| FS L&F (튜닝) | 69.44 / 9.31 / 34.33 | 73.19 / 8.09 / 29.15 | **77.59 / 6.64 / 36.43** |
| Road Anomaly (튜닝) | 82.05 / 15.73 / 58.41 | 87.97 / 9.40 / 68.77 | 87.32 / 8.87 / 67.03 |
| SMIYC Obstacle (검증) | 92.83 / 0.16 / 67.17 | 97.86 / 0.04 / 72.42 | **98.24 / 0.03 / 75.44** |
| SMIYC Anomaly (검증) | 95.49 / 2.39 / 84.37 | 69.56 / 10.44 / 58.29 | **91.63** / 12.60 / **79.17** |

- DetSeg-R도 SMIYC 두 곳에서 AP·IoU가 오른다. SMIYC Anomaly는 AP 69.56 → 91.63
- 다만 **SMIYC Anomaly의 FPR95는 나빠지고**(10.44 → 12.60), **M2A 단독(AP 95.49, IoU 84.37)보다는 여전히 낮다.** 이 데이터셋에서 DetSeg-R의 box 안 배경 오탐 문제(논문 4.2절이 인정한 한계)가 남아 있다
- FS L&F는 AP·FPR95·IoU 모두 개선되어 처음으로 M2A 단독보다 모든 지표가 좋다

## 5. 해석

1. **두 모델의 교차 확인이 IE-NMS의 과잉 억제를 고친다.** I1에서 점수 하나(objectness)로 보호하려던 시도는 실패했다. objectness는 차·사람에서 가장 높기 때문이다. M2A 점수는 반대로 차·사람에서 낮다. Cityscapes에서 이미 배운 class이기 때문이다. **같은 "보호" 규칙이라도 신호의 출처가 맞아야 작동한다**
2. **FS L&F가 논문 수치에 도달했다** (32.67 vs 32.36). 공개본 14.26 → 논문 방식 bar 24.26 → C5 32.67
3. **비용:** DetSeg-S에 M2A 추론이 추가된다 (속도 분석은 T1). DetSeg-R은 원래 M2A 점수 지도를 쓰므로 추가 비용이 사실상 없다
4. **공정성 주의:**
   - C5 아이디어의 계기(트럭 사례)는 검증셋 관찰이었다 (05 문서 4절). 다만 t는 튜닝셋에서만 골랐다
   - DetSeg-S + C5는 더 이상 "DetSeg-S 단독"이 아니라 **M2A를 함께 쓰는 하이브리드**다. 비교 대상으로 M2A 단독(threshold 탐색 IoU)도 함께 보고한다: SMIYC Obstacle 67.17 vs **80.93**, SMIYC Anomaly **84.37** vs 78.06, FS L&F 34.33 vs 32.67, RA 58.41 vs **76.82**. M2A 단독은 정답을 보고 최적 threshold를 고른 값이라 실제 배포에서는 얻을 수 없다
5. RA에서는 소폭 하락(DetSeg-S 79.25 → 76.82)한다. 인터넷 사진이라 M2A가 정상 물체에도 높은 점수를 주는 경우가 있어(사전 분석 AUC 0.716) 일부 오탐도 보호된다
