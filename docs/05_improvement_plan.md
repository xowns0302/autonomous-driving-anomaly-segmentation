## 1. 출발점 (기준선)

**"DetSeg 논문 방식"** = 공개 코드 + 논문 방식 IE-NMS bar 보정 (A3의 V1)

| | FS L&F | Road Anomaly | SMIYC Obstacle | SMIYC Anomaly |
|---|---|---|---|---|
| DetSeg-S IoU | 24.26 | 79.25 | 77.93 | 54.57 |

개선 효과는 이 기준선과 비교한다. (공개본 원본 수치도 함께 보고한다.)

## 2. 해결할 문제

IE-NMS는 ID box가 같은 자리의 OoD box를 지우게 한다. A2·A3에서 두 방향의 실패를 확인했다.

| 실패 | 내용 | 대표 사례 |
|---|---|---|
| 과소 억제 | ID 물체(차)가 OoD로 남음 | FS L&F 차량 오탐 (bar 보정으로 상당 부분 해결) |
| **과잉 억제** | 진짜 이상 물체가 ID box에 지워짐 | SMIYC Anomaly 이미지 5: OoD 0.749인 물체가 "truck" 0.572에 지워짐 / 이미지 4: 큰 이상 물체가 "road" box에 지워짐 |

bar 하나로는 둘을 동시에 해결할 수 없다 (A3 결론). → **"ID box가 OoD box를 지워도 되는 조건"을 바꾼다.**

## 3. 개선 후보 (모두 재학습 없음, τ = 0.2 고정)

| ID | 이름 | 규칙 | 근거 | 하이퍼파라미터 |
|---|---|---|---|---|
| **C1** | stuff 억제 제외 | 형태가 없는 배경 class(road, sidewalk, building, wall, vegetation, terrain, sky)의 box는 OoD box를 지우지 못한다 | 배경 영역 box는 "물체"가 아니다. 큰 물체가 배경 box와 IoU 0.5를 넘는 것은 물체가 그 영역을 덮었다는 뜻이지 같은 물체라는 뜻이 아니다 (이미지 4) | 없음 |
| **C2** | 높은 objectness 보호 | OoD 점수(objectness)가 γ 이상인 box는 ID box가 지우지 못한다 | UN branch가 매우 확신하는 물체는 ID branch의 class 판단보다 우선한다 (이미지 5: 0.749) | γ |
| C3 | 도로 문맥 재점수화 | box 바닥 중앙점이 detector 자신의 'road' 예측 box 밖이면 OoD 점수 × α | 자율주행에서 주행 영역 위 물체가 위험하다. 사전 탐색에서 도로 밖 오탐 감소 확인 | α |
| C4 | 고해상도 추론 | 입력 축소 크기를 키운다 (800×1333 → 더 크게) | 16px 미만 장애물의 약 절반이 후보조차 없다 (A2) | 크기 |

C1·C2는 과잉 억제, C3은 오탐, C4는 작은 물체 누락을 겨냥한다. **우선순위: C1·C2 → C3 → C4.**

DetSeg-S와 DetSeg-R은 같은 box를 쓰므로 모든 후보를 **양쪽에 적용**해 평가한다.

## 4. 튜닝·검증 규칙

| 데이터 | 역할 |
|---|---|
| **FS L&F + Road Anomaly** | 튜닝: 후보 선택, γ·α 등 결정 |
| **SMIYC Obstacle val + SMIYC Anomaly val** | 검증: 설정을 고정한 뒤 1회 측정 |
| FS Static | 참고 (버전 불일치) |

- 튜닝 목표: **DetSeg-S IoU의 두 튜닝셋 평균** (보조로 DetSeg-R AP·FPR95 확인)
- 하이퍼파라미터 후보값은 실행 전에 정한다: γ ∈ {0.5, 0.6, 0.7, 0.8}, α ∈ {0.3, 0.5, 0.7}
- **정직하게 밝힐 점:** C1·C2의 아이디어는 검증셋인 SMIYC Anomaly의 실패 사례(A2)를 보고 떠올렸다. 규칙의 형태는 그 관찰에서 나왔지만, **숫자(γ)는 튜닝셋에서만 정한다.** 보고서에 이 점을 명시한다

- 튜닝셋에서만 좋고 검증셋에서 나빠지면 "일반화되지 않음"으로 보고한다

## 7. 추가 후보 (2026-10-18, P1 사전 분석 이후, 실행 전 확정)

신호: **proto_box** = 1 − max cos(OoD box 안 DINOv2 ViT-S/14 패치 특징 평균, Cityscapes train prototype 380개) (PROWL 방식, [P1](experiments/P1_prowl_presignal.md))

| ID | 규칙 | 후보값 |
|---|---|---|
| **C6** | ID box는 proto_box ≥ t6인 OoD box를 지우지 못한다 (C5의 M2A 신호를 교체) | t6 ∈ {0.35, 0.40, 0.45, 0.50} |
| **C7** | IE-NMS 후 남은 OoD box 중 proto_box < t7이면 버린다 | t7 ∈ {0.25, 0.30, 0.35} |

선택 절차 (튜닝셋 FS L&F + RA, DetSeg-S IoU 평균):
1. C6 단독 4개 중 최고 t6 선택
2. C7 단독 3개 실행 (참고)
3. 1에서 고른 t6에 C7 3개를 더해 실행 → C6 단독과 C6+C7 중 최고를 최종 설정으로
4. 최종 설정을 검증셋에서 1회 (DetSeg-S, DetSeg-R) + 시간 측정 (T2 규칙)
5. 판정 기준은 5절과 같다. 추가로 C5(M2A)와 정확도·시간을 비교한다

### 7.1 선택 절차 수정 (2026-10-18, 단계 1~3 실행 후, 검증셋 평가 전)

- 문제: 원래 절차(3)는 최종 설정을 "C6 단독 vs C6+C7" 중에서 고르게 되어 있었다. 실행해 보니 **C6 단독이 모든 t6에서 기준선보다 낮았고**(최고 50.46 < 51.76), 참고로 돌린 **C7 단독이 가장 좋았다**(t7 0.35: 54.11). 원래 절차를 그대로 따르면 튜닝셋에서 더 나쁜 설정(C6 0.50 + C7 0.35: 52.87)을 고르게 된다
- 수정: **튜닝셋에서 실행한 모든 설정(기준선 포함) 중 평균 IoU가 가장 높은 것**을 최종 설정으로 한다. "튜닝셋만 보고 고른다"는 원칙은 그대로이며, 검증셋 결과를 보기 전에 정했다
- 결과: **C7 단독, t7 = 0.35**

## 9. C8 보완 후보 (2026-10-20, I6·F1·F2 이후, 실행 전 확정)

| ID | 규칙 | 후보값 |
|---|---|---|
| **C9 = C8 + M2A 거부권** | C8과 같되, C7이 지우려는 OoD box라도 box 안 M2A 점수 평균 ≥ v이면 지우지 않는다 (C5 t = 0.5, C7 t7 = 0.35 고정) | v ∈ {0.5, 0.6, 0.7, 0.8} |
| **C10 = C5 + mask 단위 C7** | C7의 PROWL 신호를 box 대신 **SAM mask** 안 패치(mask가 절반 이상 덮는 패치, 없으면 가장 많이 덮는 패치 1개)의 특징 평균으로 계산하고, proto_mask < t7m인 mask를 버린다 (C5 t = 0.5 고정, box 단위 C7은 끔) | t7m ∈ {0.25, 0.30, 0.35, 0.40} |

- 근거: F1·I6에서 C7의 손해는 "아는 물체를 닮은 이상 물체(트레일러, 라바콘)를 지우는 것"이었다. C9는 M2A가 강하게 이상이라고 하면 C7을 막고, C10은 box 안 배경(도로 등)이 섞이지 않게 물체 모양 안에서만 비교한다 (PROWL 논문의 mask 단위 판정에 더 가깝다)
- **정직하게 밝힐 점:** 두 아이디어 모두 검증셋(SMIYC Anomaly 이미지 5, 트레일러)의 실패를 보고 떠올렸다. 트레일러 box의 M2A 평균(0.72)도 이미 알고 있다. 숫자는 튜닝셋에서만 고른다
- 선택: 후보마다 튜닝셋(FS L&F + RA) DetSeg-S IoU 평균. 각 ID에서 최고 설정 1개를 고른다
- 채택: 고른 설정의 튜닝 평균이 **C8(57.42)보다 높을 때만** 최종 방법을 바꾼다. 채택 여부와 상관없이 고른 설정은 검증셋에서 1회 평가해 추가 실험으로 보고한다
- C9·C10이 모두 C8보다 높으면, 고른 값 그대로 C9 + C10 조합을 추가 튜닝 없이 튜닝셋·검증셋에서 1회씩 평가한다
- 평가: DetSeg-S IoU (튜닝·검증), F2 물체 단위 지표. DetSeg-R은 C9만 (C10은 SAM mask를 쓰지 않는 DetSeg-R에 적용할 수 없다)
- 구현 확인: C9 v = 1.1이면 C8과 같은 값, C10 t7m = −1이면 C5와 같은 값이어야 한다

## 10. 새 검증셋: Lost and Found 원본 테스트셋 (2026-10-21, 결과 보기 전 확정)

- 목적: (1) 기존 검증셋(SMIYC 40장)에는 오탐이 거의 없어(C5 기준 2개, 27개) C7(PROWL)의 오탐 감소 효과를 확인할 수 없었다. (2) C9의 거부권은 기존 검증셋 사진을 보고 떠올렸다. **한 번도 보지 않은 데이터**로 다시 확인한다
- 데이터: Lost and Found (Pinggera et al., IROS 2016) **test 분할**. 출처는 공식 사이트가 닫혀 비공식 미러(Hugging Face `kumuji/lost_and_found`, OoDIS 저자)를 쓴다. 비상업 연구 목적 라이선스, 재배포하지 않는다
- **연습용 FS L&F와 겹치는 사진은 뺀다** (FS L&F는 Lost and Found에서 뽑은 부분집합). 겹침은 이미지 내용 비교로 찾고, 뺀 장수를 보고한다
- 라벨 변환: 데이터셋 문서(laf_table.pdf)와 기존 논문들의 관례를 따른다 — 장애물 = 이상(1), 도로 = 정상(0), 그 밖 = 평가 제외(255). 세부 규칙은 결과를 보기 전에 이 절 아래에 적는다
- 평가 대상 (설정 모두 고정, 다시 튜닝하지 않음): 공개본, 기준선(논문 방식 bar), C5(t = 0.5), C8(C5 + C7 t7 = 0.35), **C9(C8 + 거부권 v = 0.7)**, 참고로 M2A 단독(최적 threshold)
- 지표: DetSeg-S IoU, 물체 단위 미탐·오탐 (F2와 같은 기준: 50px 이상, 면적 50% 이상 칠하면 찾음, 정답과 전혀 안 겹친 덩어리 = 오탐)
- **1회만 평가하고, 결과가 나빠도 그대로 보고한다.** 최종 방법(C9)은 이 결과로 바꾸지 않는다
- 예상(사전 기록): 주차 차량이 많은 도시 도로라 C5 대비 C8·C9의 오탐 감소가 보일 것. 같은 도시·같은 차량이라 연습용 FS L&F와 환경이 비슷하므로, 완전히 다른 환경으로의 일반화 근거는 아니다
