# Autonomous Driving Anomaly Segmentation

Camera-based road anomaly / OoD object segmentation study for autonomous driving (graduation project).

- Main paper: **DetSeg** — *Beyond Pixel Uncertainty: Bounding the OoD Objects in Road Scenes* (ICCV 2025)
- Comparison: **S2M** — *Segment Every Out-of-Distribution Object* (CVPR 2024)
- Related / latest trend: **ClimaOoD** (arXiv 2026)

Current status, decisions, and TODOs: see [PROJECT_STATUS.md](PROJECT_STATUS.md).
